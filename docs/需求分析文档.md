## 1. 引言

### 1.1 项目背景

随着健身行业的高速发展，传统健身房普遍存在管理效率低、会员体验差、数据分散等问题。本系统旨在通过信息化手段，对健身房的会员、教练、课程、器材、费用等核心业务进行统一管理，提升运营效率，优化会员体验，并为管理层提供科学的数据决策支持。

### 1.2 项目目标

1. 实现健身房日常运营业务的全面线上化管理
2. 为会员提供便捷的课程预约、体测记录、积分兑换服务
3. 为教练提供学员管理、排课、作业布置等工作支持
4. 为管理员提供完整的数据统计与运营分析功能
5. 构建稳定、安全、可扩展的健身房信息化平台

### 1.3 术语定义

| 术语 | 定义 |
|-----|------|
| 会员 | 在健身房注册并购买会员卡的正式用户 |
| 教练 | 健身房聘用的具有专业资质的健身指导人员 |
| 管理员 | 健身房运营管理人员，拥有系统全部管理权限 |
| 会员卡 | 会员购买的服务凭证，记录有效期、剩余次数等信息 |
| 会员等级 | 根据消费和活跃度划分的会员等级体系 |
| 体测 | 体质测试，对会员身体指标进行专业检测 |
| 课时费 | 教练每完成一节课程获得的报酬 |
| 积分 | 会员参与各项活动获取的奖励积分，可用于兑换商品或课程 |

## 2. 业务概述

### 2.1 健身房运营模式

本健身房采用"会员制+课程预约"的混合运营模式：

- **会员制**: 会员需购买会员卡（按年收费），享有基础健身设施使用权和会员专属权益
- **课程预约制**: 会员可预约教练开设的团课或私教课，系统自动管理容量和签到
- **积分激励制**: 会员通过签到、完成课程等行为积累积分，积分可兑换商品或课程
- **教练绩效制**: 教练收入由基本工资、课时费和销售提成构成，系统自动核算绩效

### 2.2 系统用户角色

本系统包含三类用户角色，各角色拥有独立的操作界面和功能权限：

| 角色 | 用户说明 | 主要职责 |
|-----|---------|---------|
| 管理员 | 健身房运营管理人员 | 全面管理系统所有模块，包括会员管理、教练管理、课程管理、器材管理、积分商城管理、数据统计 |
| 教练 | 持有专业资质的健身指导人员 | 管理个人课程、查看学员信息、布置作业、回复会员消息、录入体测数据 |
| 会员 | 在健身房注册的正式会员 | 预约课程、签到、查看体测记录、积分兑换、联系教练、接收消息通知 |

### 2.3 健身房业务流程总览

```
会员注册 ──→ 购买会员卡 ──→ 成为正式会员
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
          预约课程        日常签到        体测评估
              │               │               │
              ▼               ▼               ▼
          签到上课        累计积分        生成报告
              │               │               │
              ▼               ▼               ▼
        课程评价        积分兑换        教练指导
              │               │               │
              ▼               ▼               ▼
          教练绩效       商品/课程      持续健身
```

## 3. 功能需求分析

### 3.1 用户登录与权限管理

#### 3.1.1 登录认证

**功能描述**: 支持管理员、教练、会员三种角色的统一登录入口，根据用户类型自动路由至对应的工作台。

**详细需求**:

- [REQ-001] 系统提供统一的登录页面，支持用户名+密码+角色类型的三要素登录
- [REQ-002] 登录成功后返回 JWT Token，有效期为24小时
- [REQ-003] 登录失败时提示"用户名或密码错误"，连续失败5次后锁定账户15分钟
- [REQ-004] 支持用户修改个人密码
- [REQ-005] 支持会员注册功能，由管理员审核后生效

**业务规则**:

- 不同角色登录后进入各自的专属首页
- 教练和会员禁止进入管理员数据统计首页
- Token 过期后自动跳转至登录页面

#### 3.1.2 权限控制

**功能描述**: 基于角色的访问控制（RBAC），不同角色只能访问其权限范围内的功能。

**详细需求**:

- [REQ-006] 管理员拥有系统全部功能的访问和管理权限
- [REQ-007] 教练只能访问教练端相关功能（排课、学员、体测、作业、消息）
- [REQ-008] 会员只能访问会员端相关功能（课程预约、个人中心、积分、体测等）
- [REQ-009] 未登录用户访问受保护页面时，自动跳转至登录页

### 3.2 会员管理模块

#### 3.2.1 会员信息管理

**功能描述**: 对会员基础信息进行全生命周期管理。

**详细需求**:

- [REQ-010] 管理员可新增会员，录入姓名、性别、出生日期、手机号、邮箱等信息
- [REQ-011] 管理员可编辑、查看、搜索、筛选会员信息
- [REQ-012] 会员可上传个人头像
- [REQ-013] 管理员可为会员分配专属教练
- [REQ-014] 支持按姓名、手机号、会员等级、健身教练等条件检索会员
- [REQ-015] 支持会员信息导出（Excel格式）

**业务规则**:

- 会员手机号作为唯一标识，不可重复
- 会员最后一次访问时间自动记录
- 会员注销需经管理员审核

#### 3.2.2 会员等级管理

**功能描述**: 建立会员等级体系，不同等级享有不同的折扣率和积分倍率。

**详细需求**:

- [REQ-016] 管理员可新增、编辑、删除会员等级
- [REQ-017] 系统预设四个默认等级：青铜、白银、黄金、钻石
- [REQ-018] 会员等级根据累计积分自动升级
- [REQ-019] 等级越高，享受的购物折扣和积分倍率越高

**业务规则**:

| 等级 | 积分范围 | 购物折扣 | 积分倍率 | 年费 |
|-----|---------|---------|---------|------|
| 青铜 | 0~999 | 98折 | 1.0倍 | 99元 |
| 白银 | 1000~4999 | 95折 | 1.2倍 | 199元 |
| 黄金 | 5000~19999 | 90折 | 1.5倍 | 399元 |
| 钻石 | 20000+ | 80折 | 2.0倍 | 799元 |

- 积分按月统计，系统自动判定等级是否需要升级
- 会员等级不会降级

#### 3.2.3 会员卡管理

**功能描述**: 管理会员卡的开卡、续费、挂失、补办等操作。

**详细需求**:

- [REQ-020] 管理员可为会员办理新会员卡，设置卡类型（年卡、季卡、月卡、次卡）
- [REQ-021] 支持会员卡续费，自动更新有效期
- [REQ-022] 支持会员卡挂失和补办，补办需收取工本费
- [REQ-023] 会员卡状态：正常、挂失、已补办
- [REQ-024] 管理员可查看所有会员卡的使用情况（剩余次数/余额）
- [REQ-025] 支持按会员姓名、卡号、状态等条件查询会员卡

**业务规则**:

- 年卡：按自然年计算有效期
- 季卡：有效期90天
- 月卡：有效期30天
- 次卡：按次数消费，不限时间

#### 3.2.4 会员签到

**功能描述**: 记录会员每次到店健身的签到信息，配合积分奖励机制。

**详细需求**:

- [REQ-026] 会员每日可签到一次，系统记录签到时间和日期
- [REQ-027] 签到自动奖励积分（基础10积分/次）
- [REQ-028] 连续签到天数越多，单次签到奖励积分越高
- [REQ-029] 管理员可查看所有签到记录，按日期范围检索
- [REQ-030] 断签后连续天数归零，重新从1天开始计算

**业务规则**:

| 连续签到天数 | 单次奖励积分 |
|-----------|-----------|
| 1~7天 | 10分 |
| 8~30天 | 15分 |
| 31~60天 | 20分 |
| 61天以上 | 30分 |

#### 3.2.5 体测记录

**功能描述**: 记录会员的体质检测数据，生成健康报告。

**详细需求**:

- [REQ-031] 教练可为会员录入体测数据，管理员可查看所有体测记录
- [REQ-032] 体测指标包括：身高、体重、BMI、体脂率、肌肉量、含水量、内脏脂肪、静息代谢、胸围、腰围、臀围、臂围、腿围、心率、血压
- [REQ-033] 系统自动计算BMI和健康评分
- [REQ-034] 会员可查看个人体测历史记录和趋势变化
- [REQ-035] 支持体测数据导出

**业务规则**:

- BMI = 体重(kg) / 身高(m)²
- BMI正常范围：18.5 ~ 24，+10分；低于或高于正常范围扣分
- 体脂率正常标准：男性<25%，女性<30%，达标+10分
- 健康评分范围：0~100分

#### 3.2.6 消费记录

**功能描述**: 记录会员所有消费行为，包括课程消费、商品购买等。

**详细需求**:

- [REQ-036] 管理员可为会员办理消费，包括课程预约购买、会员卡购买、商品购买
- [REQ-037] 系统自动生成订单编号（格式：消费时间戳+随机码）
- [REQ-038] 消费时支持积分抵扣（100积分=1元）
- [REQ-039] 消费完成后，会员获得相应的积分奖励（消费1元=1积分，乘以等级倍率）
- [REQ-040] 管理员可按会员姓名、日期范围、消费类型等检索消费记录
- [REQ-041] 支持消费统计报表，按日/月/年查看消费总额

**业务规则**:

- 消费记录一旦生成不可删除，只能退款冲正
- 积分不足时不允许使用积分抵扣
- 消费积分按"实际支付金额"计算

### 3.3 教练管理模块

#### 3.3.1 教练信息管理

**功能描述**: 对教练的基础信息、资质进行管理。

**详细需求**:

- [REQ-042] 管理员可新增、编辑、查看、搜索教练信息
- [REQ-043] 教练信息包括：姓名、性别、出生日期、手机号、邮箱、专长领域、工作年限、资质证书、头像
- [REQ-044] 支持按姓名、手机号、专长领域检索教练
- [REQ-045] 管理员可设置教练的启用/禁用状态

#### 3.3.2 教练证书管理

**功能描述**: 集中管理教练的各类资质证书。

**详细需求**:

- [REQ-046] 管理员可为教练上传证书图片（支持jpg/png格式，最大5MB）
- [REQ-047] 证书信息包括：证书名称、证书类型、证书编号、颁发机构、颁发日期、有效期
- [REQ-048] 系统自动提醒即将过期（30天内到期）的证书
- [REQ-049] 证书审核状态：待审核、已通过、已驳回

#### 3.3.3 教练专长管理

**功能描述**: 管理每位教练的专业领域和擅长项目。

**详细需求**:

- [REQ-050] 管理员可为教练添加多个专长标签（如：增肌、减脂、塑形、康复训练、拉伸等）
- [REQ-051] 教练专长在会员端课程预约时可查看

#### 3.3.4 教练排班管理

**功能描述**: 管理员为教练安排每周的可用授课时间。

**详细需求**:

- [REQ-052] 管理员可为教练创建排班计划（日期、时间段、课程类型、上课地点）
- [REQ-053] 排班状态：可用、已约满、休息
- [REQ-054] 管理员可修改、删除教练排班
- [REQ-055] 教练可查看自己的排班计划

#### 3.3.5 教练调班管理

**功能描述**: 允许教练之间进行班次调换申请与审批。

**详细需求**:

- [REQ-056] 教练可发起调班申请，选择目标日期和时间段，填写调班原因
- [REQ-057] 管理员审核调班申请，通过或驳回
- [REQ-058] 调班申请通过后，双方排班自动更新

#### 3.3.6 教练工资管理

**功能描述**: 按月核算每位教练的工资明细。

**详细需求**:

- [REQ-059] 管理员按月为每位教练生成工资单
- [REQ-060] 工资构成：基本工资 + 课时费 + 销售提成 + 奖金 - 扣款
- [REQ-061] 课时费根据教练本月完成的课程数量计算
- [REQ-062] 销售提成根据教练推荐会员购买课程的金额按比例计算
- [REQ-063] 管理员可标记工资单为"已发放"状态

**工资计算公式**:
```
总工资 = 基本工资 + (课时数 × 课时单价) + (销售金额 × 提成比例) + 奖金 - 扣款
```

#### 3.3.7 教练绩效管理

**功能描述**: 对教练的工作表现进行周期性评估。

**详细需求**:

- [REQ-064] 管理员按月对教练进行绩效评估
- [REQ-065] 绩效维度：出勤率（权重25%）、教学质量（权重30%）、服务水平（权重25%）、销售能力（权重20%）
- [REQ-066] 根据总分评定绩效等级：优秀、良好、合格、不合格
- [REQ-067] 绩效结果作为奖金发放和晋升的参考依据

#### 3.3.8 教练评价管理

**功能描述**: 会员对教练的服务进行评价。

**详细需求**:

- [REQ-068] 会员完成课程后可对教练进行评价（1~5星）
- [REQ-069] 评价维度：教学能力、服务态度、专业水平
- [REQ-070] 教练可查看自己的评价记录和平均评分
- [REQ-071] 教练可对会员评价进行回复
- [REQ-072] 管理员可查看所有教练评价

### 3.4 课程管理模块

#### 3.4.1 课程信息管理

**功能描述**: 管理员对健身房开设的所有课程进行管理。

**详细需求**:

- [REQ-073] 管理员可新增、编辑、删除、上架/下架课程
- [REQ-074] 课程信息包括：课程名称、所属分类、上课教练、上课时间、时长、价格、容量、上课地点、课程简介
- [REQ-075] 支持按课程名称、教练、课程分类等条件检索课程
- [REQ-076] 课程状态：上架、下架
- [REQ-077] 管理员可按日期查看所有课程的排期安排

#### 3.4.2 课程分类管理

**功能描述**: 对课程进行分类管理，便于会员检索。

**详细需求**:

- [REQ-078] 管理员可新增、编辑、删除课程分类
- [REQ-079] 支持设置分类的排序顺序
- [REQ-080] 课程分类示例：私教课、团课、有氧训练、力量训练、瑜伽、动感单车

#### 3.4.3 课程预约

**功能描述**: 会员预约感兴趣的课程。

**详细需求**:

- [REQ-081] 会员可查看所有可预约课程及剩余名额
- [REQ-082] 会员选择课程和预约时间，确认预约
- [REQ-083] 系统自动检查：会员卡是否有效、积分是否充足、课程是否还有名额
- [REQ-084] 预约成功后，系统自动扣除积分，发送课程提醒
- [REQ-085] 会员可取消预约（课程开始前1小时可取消）
- [REQ-086] 会员完成课程后自动签到

**业务规则**:

- 预约课程需消耗积分（根据课程价格扣减）
- 课程开始前自动发送提醒通知
- 爽约（未签到且未取消）超过3次，限制预约权限7天

#### 3.4.4 课程评价

**功能描述**: 会员对已完成的课程进行评价。

**详细需求**:

- [REQ-087] 会员可对已完成的课程进行1~5星评分，并填写评价内容
- [REQ-088] 可上传评价图片（最多3张）
- [REQ-089] 教练可回复会员评价
- [REQ-090] 管理员可查看所有课程评价，敏感内容可删除
- [REQ-091] 课程完成后，会员获得评价积分奖励

### 3.6 积分商城模块

#### 3.6.1 积分商品管理

**功能描述**: 管理员管理积分兑换商品。

**详细需求**:

- [REQ-101] 管理员可新增、编辑、删除、上架/下架积分商品
- [REQ-102] 商品类型：实物商品、健身课程
- [REQ-103] 商品信息包括：商品名称、描述、所需积分、库存、图片
- [REQ-104] 支持按商品名称、类型检索
- [REQ-105] 库存不足时自动下架

#### 3.6.2 积分兑换

**功能描述**: 会员使用积分兑换商品或课程。

**详细需求**:

- [REQ-111] 会员可查看积分兑换历史记录

#### 3.6.4 积分明细

**功能描述**: 会员查看积分的收支明细。

**详细需求**:

- [REQ-113] 会员可查看积分余额和收支明细

## 4. 非功能需求分析

### 4.1 性能需求

| 指标 | 要求 |
|-----|------|
| 系统响应时间 | 普通操作<2秒，复杂查询<5秒 |
| 并发用户数 | 支持同时在线100人以上 |
| 数据准确性 | 财务类数据（消费、工资）误差为零 |
| 系统可用性 | 7×24小时可用（维护窗口除外） |

### 4.2 安全性需求

| 需求 | 说明 |
|-----|------|
| 身份认证 | 所有接口需通过JWT Token验证 |
| 密码加密 | 密码使用BCrypt加密存储 |
| 越权防护 | 基于角色的接口权限校验，防止越权访问 |
| 数据隔离 | 教练只能查看自己学员的数据 |
| 日志记录 | 关键操作（删除、扣费）需记录操作日志 |

### 4.3 易用性需求

| 需求 | 说明 |
|-----|------|
| 界面友好 | 使用Element UI标准组件，保持操作一致性 |
| 错误提示 | 操作失败时显示明确的错误信息 |
| 加载状态 | 异步操作显示loading动画 |
| 空状态 | 列表为空时显示友好提示 |

### 4.4 数据管理需求

| 需求 | 说明 |
|-----|------|
| 数据备份 | 每日凌晨3点自动备份数据库 |
| 逻辑删除 | 删除操作采用逻辑删除，不物理删除数据 |
| 文件存储 | 上传文件存储在服务器本地uploads目录 |

## 8. 附录

### 8.1 业务规则汇总表

| 编号 | 规则名称 | 规则内容 |
|-----|---------|---------|
| BR-001 | 会员卡有效期 | 年卡按自然年计算；次卡不限时间，按次数消费 |
| BR-002 | 积分倍率 | 不同等级会员享有不同的积分获取倍率 |
| BR-003 | 预约取消 | 课程开始前1小时可取消，爽约3次限制预约7天 |
| BR-004 | 逻辑删除 | 所有删除操作均采用逻辑删除（deleted=1） |
| BR-005 | 密码安全 | 密码使用BCrypt加密，前端不存储明文密码 |
| BR-006 | JWT过期 | Token有效期24小时，过期后需重新登录 |
| BR-007 | 会员等级 | 等级根据累计积分自动升级，不会降级 |
| BR-008 | 连续签到 | 断签后连续天数归零重新计算 |

### 8.2 接口约束

| 约束项 | 规定 |
|-------|------|
| 通信协议 | HTTPS（生产环境） |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 日期格式 | yyyy-MM-dd HH:mm:ss |
| 分页参数 | pageNum（页码，从1开始）、pageSize（每页条数，默认10） |
