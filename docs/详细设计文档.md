### 2.2 登录认证流程

```java
// AuthController.java
// POST /auth/login
public ApiResponse<LoginResponse> login(LoginRequest loginRequest) {
    // 1. 参数校验
    if (StringUtils.isBlank(loginRequest.getUsername())
        || StringUtils.isBlank(loginRequest.getPassword())) {
        return ApiResponse.error("用户名和密码不能为空");
    }

    // 2. Spring Security 认证
    Authentication authentication = authenticationManager.authenticate(
        new UsernamePasswordAuthenticationToken(
            loginRequest.getUsername(),
            loginRequest.getPassword(),
            loginRequest.getUserType()
        )
    );

    // 3. 生成 JWT Token
    UserDetails userDetails = (UserDetails) authentication.getPrincipal();
    String token = jwtUtil.generateToken(userDetails.getUsername());

    // 4. 查询用户完整信息
    UserInfo user = userInfoMapper.selectByUsername(loginRequest.getUsername());

    // 5. 构建响应
    LoginResponse response = new LoginResponse();
    response.setToken(token);
    response.setUsername(user.getUsername());
    response.setUserId(user.getUserId());
    response.setUserType(user.getUserType());
    response.setMemberId(user.getMemberId());
    response.setCoachId(user.getCoachId());
    response.setAvatar(user.getAvatar());

    return ApiResponse.success("登录成功", response);
}
```

### 2.3 JWT 认证过滤器

```java
// JwtAuthenticationFilter.java
// 继承 OncePerRequestFilter，每请求执行一次
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain) throws Exception {
        // 1. 从请求头获取 Token
        String authHeader = request.getHeader("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            chain.doFilter(request, response);
            return;
        }

        String token = authHeader.substring(7);

        // 2. 验证 Token
        if (jwtUtil.validateToken(token)) {
            String username = jwtUtil.getUsernameFromToken(token);
            String role = jwtUtil.getRoleFromToken(token);
            Integer userType = jwtUtil.getUserTypeFromToken(token);

            // 3. 存入 SecurityContext，供后续 Controller 使用
            UsernamePasswordAuthenticationToken authentication =
                new UsernamePasswordAuthenticationToken(username, null, null);
            authentication.setDetails(new SecurityUserDetails(username, role, userType));
            SecurityContextHolder.getContext().setAuthentication(authentication);
        }

        chain.doFilter(request, response);
    }
}
```

### 2.4 签到业务流程（积分累计核心算法）

```java
// MemberSigninController.java
// POST /member/signin
public ApiResponse<String> sign(MemberSignin signin) {
    Long memberId = signin.getMemberId();

    // ① 检查今日是否已签到
    Boolean alreadySigned = memberSigninService.checkTodaySignin(memberId);
    if (alreadySigned) {
        return ApiResponse.error("今日已签到，明天再来吧！");
    }

    // ② 查询昨日连续签到天数
    Integer consecutiveDays = memberSigninService.getConsecutiveDays(memberId);
    int newConsecutive = (consecutiveDays == null ? 0 : consecutiveDays) + 1;

    // ③ 计算本次签到积分（连续天数越高，积分越多）
    int pointsEarned = calculateSigninPoints(newConsecutive);
    signin.setPointsEarned(pointsEarned);
    signin.setConsecutiveDays(newConsecutive);
    signin.setSigninDate(LocalDate.now());
    signin.setSigninTime(LocalDateTime.now());
    signin.setSigninType("DAILY");
    signin.setCreateTime(LocalDateTime.now());

    // ④ 保存签到记录
    memberSigninService.save(signin);

    // ⑤ 更新会员积分余额
    memberInfoService.addPoints(memberId, pointsEarned, "signin", "签到奖励");

    // ⑥ 记录积分明细
    memberPointsRecordService.addRecord(memberId,
        PointsTaskType.SIGNIN.getKey(),
        String.valueOf(signin.getSigninId()),
        "signin",
        "签到+" + pointsEarned + "积分");

    return ApiResponse.success("签到成功！获得 " + pointsEarned + " 积分", null);
}

/**
 * 根据连续签到天数计算积分
 * 1~7天: 10分 | 8~30天: 15分 | 31~60天: 20分 | 61天以上: 30分
 */
private int calculateSigninPoints(int consecutiveDays) {
    if (consecutiveDays <= 7) return 10;
    if (consecutiveDays <= 30) return 15;
    if (consecutiveDays <= 60) return 20;
    return 30;
}
```

### 2.5 体测数据录入与健康评分计算

```java
// MemberBodyTestController.java
// POST /member/bodyTest/add
public ApiResponse<String> add(MemberBodyTest bodyTest) {
    // ① 计算 BMI
    if (bodyTest.getHeight() != null && bodyTest.getWeight() != null) {
        double heightM = bodyTest.getHeight() / 100.0; // cm → m
        double bmi = bodyTest.getWeight() / (heightM * heightM);
        bodyTest.setBmi((double) Math.round(bmi * 10) / 10);
    }

    // ② 计算健康评分（0~100分）
    int healthScore = 100;

    // BMI 评分（正常范围 18.5~24）
    if (bodyTest.getBmi() != null) {
        if (bodyTest.getBmi() < 18.5 || bodyTest.getBmi() > 24) {
            healthScore -= 10;
        }
    }

    // 体脂率评分（正常：男性<25%，女性<30%）
    if (bodyTest.getBodyFatRate() != null) {
        if (bodyTest.getBodyFatRate() >= 25) {
            healthScore -= 10;
        }
    }

    // 血压评分（正常：收缩压<140 且 舒张压<90）
    if (bodyTest.getBloodPressureHigh() != null
        && bodyTest.getBloodPressureLow() != null) {
        if (bodyTest.getBloodPressureHigh() >= 140
            || bodyTest.getBloodPressureLow() >= 90) {
            healthScore -= 10;
        }
    }

    bodyTest.setHealthScore(Math.max(0, healthScore));

    // ③ 生成检测结论
    String result = healthScore >= 80 ? "优秀" :
                     healthScore >= 60 ? "良好" :
                     healthScore >= 40 ? "一般" : "需加强";
    bodyTest.setTestResult(result);
    bodyTest.setCreateTime(LocalDateTime.now());

    memberBodyTestService.save(bodyTest);
    return ApiResponse.success("体测数据录入成功，健康评分：" + healthScore, null);
}
```

### 2.6 课程预约流程（积分扣减核心）

```java
// CourseBookingController.java
// POST /course-booking
public ApiResponse<String> save(CourseBooking courseBooking) {
    Long memberId = courseBooking.getMemberId();

    // ① 校验会员卡是否有效
    MemberCard card = memberCardService.getValidCard(memberId);
    if (card == null) {
        return ApiResponse.error("请先办理会员卡");
    }

    // ② 校验课程是否还有名额
    CourseInfo course = courseInfoService.getById(courseBooking.getCourseId());
    if (course.getCurrentCapacity() >= course.getMaxCapacity()) {
        return ApiResponse.error("该课程已约满");
    }

    // ③ 检查积分是否充足
    MemberInfo member = memberInfoService.getById(memberId);
    if (member.getPoints() < course.getPrice()) {
        return ApiResponse.error("积分不足，当前积分：" + member.getPoints());
    }

    // ④ 扣除积分
```

```java
// 每10分钟执行一次：查找开课前1小时内且未发送提醒的记录
@Scheduled(fixedRate = 600000)
public void sendClassReminders() {
    LocalDateTime now = LocalDateTime.now();
    LocalDateTime oneHourLater = now.plusHours(1);

    // ① 查询所有未提醒且开课时间在 [now, now+1h] 区间的记录
    LambdaQueryWrapper<CourseReminder> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(CourseReminder::getRemindStatus, 0)
           .le(CourseReminder::getClassTime, oneHourLater)
           .ge(CourseReminder::getClassTime, now)
           .apply("deleted = 0");

    List<CourseReminder> reminders = reminderMapper.selectList(wrapper);

    for (CourseReminder reminder : reminders) {
        // ② 构造提醒消息内容
        String content = String.format(
            "您报名的「%s」将于 %s 开课，请提前到达%s做好准备！",
            reminder.getCourseName(),
            reminder.getClassTime().toString().replace("T", " "),
            reminder.getLocation() != null ? "（地点：" + reminder.getLocation() + "）" : ""
        );

        // ③ 推送会员消息
        memberMessageService.pushMessage(
            reminder.getMemberId(),
            "reminder",
            "课程提醒",
            content,
            String.valueOf(reminder.getBookingId()),
            "course_reminder"
        );

        // ④ 更新提醒状态为已发送
        reminder.setRemindStatus(1);
        reminder.setRemindTime(LocalDateTime.now());
```

### 3.2 会员等级自动升级

会员等级根据 `member_info.points`（累计积分）自动判定，升级逻辑在 `MemberLevelServiceImpl` 中实现：

| 等级编码 | 积分下限 | 积分上限 | 折扣率 | 积分倍率 |
|---------|---------|---------|--------|---------|
| BRONZE | 0 | 999 | 0.98 | 1.0 |
| SILVER | 1000 | 4999 | 0.95 | 1.2 |
| GOLD | 5000 | 19999 | 0.90 | 1.5 |
| DIAMOND | 20000 | 无上限 | 0.80 | 2.0 |

**升级触发时机**：每次会员积分变动时（签到、消费、兑换等），自动检查当前积分是否满足更高等级条件。

### 3.3 会员积分计算

```
消费获得积分 = 实际支付金额 × 会员等级积分倍率

示例：
- 黄金会员（倍率1.5）消费100元 → 获得 150 积分
- 钻石会员（倍率2.0）消费100元 → 获得 200 积分

积分抵扣汇率：100积分 = 1元
```

### 3.4 教练工资计算

```
总工资 = 基本工资 + 课时费合计 + 销售提成 + 奖金 - 扣款

其中：
- 课时费合计 = 本月完成课时数 × 课时单价
- 销售提成 = 教练推荐课程销售总额 × 提成比例
```

### 3.5 教练绩效评分

```
总分 = 出勤得分 × 0.25 + 教学质量得分 × 0.30 + 服务水平得分 × 0.25 + 销售能力得分 × 0.20
```

## 9. 物理删除与逻辑删除

本系统所有业务表均采用**逻辑删除**策略，通过 MyBatis Plus 的 `@TableLogic` 注解实现：

```java
@TableLogic
private Integer deleted;  // 0=未删除，1=已删除
```

查询时 MyBatis Plus 自动拼接 `WHERE deleted = 0` 条件，删除操作自动变为 UPDATE 设置 deleted=1，无需手动处理。

**例外情况**：系统日志表（操作日志）、定时任务执行记录表可使用物理删除。
